### Java - Creating and Destroying Objects POC

**Java - Creating and Destroying Objects**

### Tech Stack
* Java 25 (LTS)
* Maven 3.x
* JUnit 6.1.3

### How to Build
```bash
mvn clean compile
```

### How to Run
```bash
mvn exec:java
```

Or run directly:
```bash
java -cp target/classes com.mariofernandes.javapoc.cdo.Main
```
